# Запуск SimpleWMS для разработки

## Что нужно

- JDK 17 или новее. Проверить: `java -version`. Если в системе есть Java 8 и она стоит в PATH раньше, Gradle запустится на ней, и сборка упадёт с ошибкой «requires at least JVM runtime version 17».
- Docker Desktop (для PostgreSQL). Можно и локальный PostgreSQL 16.
- IntelliJ IDEA или Gradle из командной строки

## Если Gradle не скачивается

Ошибка `Connection reset` при загрузке с `services.gradle.org`:
1. Скачать `gradle-8.12.1-bin.zip` в браузере (или с зеркала `https://mirrors.cloud.tencent.com/gradle/`).
2. Положить zip, не распаковывая, в папку `%USERPROFILE%\.gradle\wrapper\dists\gradle-8.12.1-bin\<папка со случайным именем>\`.
3. Повторить `gradlew.bat bootRun`.

## Первый запуск

1. Скопировать `.env.example` в `.env`. При необходимости поменять порт и пароль.
   Если на компьютере уже работает свой PostgreSQL на 5432, поставить `DB_PORT=5433`.
2. Поднять БД:
   ```
   docker compose up -d
   docker compose ps        # статус db должен быть healthy
   ```
3. Запустить приложение из корня проекта:
   ```
   gradlew.bat bootRun      # Windows
   ./gradlew bootRun        # Linux/macOS
   ```
   В IntelliJ: конфигурация `SimpleWmsv2Application`, рабочая папка — корень проекта.
4. Открыть http://localhost:8080

## Как создаются схема и данные

- Таблицы создаёт Hibernate (`ddl-auto=update`).
- После этого Spring выполняет скрипты из `SQL/migrations/`:
  - `V001__seed_reference_data.sql` — роли, администратор, ABC-классы, системные зоны и ячейки (приёмка id=1, отгрузка id=2);
  - `V002__seed_demo_data.sql` — демо-справочники и товары. Выполняется только в профиле `dev`.
- Скрипты идемпотентны: при каждом старте добавляют только отсутствующие записи.
- Скрипты ищутся относительно рабочей папки, поэтому приложение запускается из корня проекта.

## Профили

| Профиль | Назначение | Данные |
|---|---|---|
| `dev` (по умолчанию) | разработка, SQL в логе | V001 + V002 |
| `prod` | боевой запуск, параметры БД только из окружения | V001 |

Профиль задаётся переменной окружения `SPRING_PROFILES_ACTIVE`.

## Сброс БД

```
docker compose down -v   # удаляет том с данными
docker compose up -d
```
