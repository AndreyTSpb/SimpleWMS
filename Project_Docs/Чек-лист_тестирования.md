# Чек-лист ручного тестирования интерфейса

Проверяет полный складской цикл через интерфейс на демо-данных. Выполняется после автотестов
(`.\gradlew.bat test`) перед сдачей версии или показом.

**Подготовка**

1. Чистая база: `docker compose down -v`, затем `docker compose up -d` (демо-данные загрузятся при старте приложения).
2. `.\gradlew.bat bootRun`, открыть http://localhost:8080.
3. Пользователи: `admin/admin` (Администратор), `manager/manager` (Менеджер склада), `storekeeper/storekeeper` (Кладовщик).

Отметка: ✅ — как ожидается, ❌ — расхождение (записать, что произошло).

## 1. Вход и права

| № | Действие | Ожидаемый результат | Отметка |
|---|---|---|---|
| 1.1 | Открыть любую страницу без входа | Перенаправление на страницу входа | |
| 1.2 | Войти с неверным паролем | Сообщение об ошибке, вход не выполнен | |
| 1.3 | Войти как `storekeeper` | В меню нет «Заказы», «Отчёты», «Справочники», «Администрирование», «Интеграция с ERP» | |
| 1.4 | Кладовщиком открыть адрес `/warehouse_status` вручную | Страница «Недостаточно прав» (403) | |
| 1.5 | Войти как `manager` | Есть «Заказы», «Отчёты», «Справочники», «Интеграция с ERP»; нет «Администрирования» | |
| 1.6 | Войти как `admin` | Доступны все разделы, включая «Сотрудники» и «Пользователи» | |
| 1.7 | Нажать «Выход» | Возврат на страницу входа с сообщением о выходе | |
