# Документация SimpleWMS

Система управления складом (WMS) — дипломный проект. Java 17, Spring Boot 3.4, PostgreSQL 16, Thymeleaf,
REST API для ERP, Docker Compose.

Материалы:
- `diagrams/*.mmd` — исходники диаграмм (Mermaid; открываются в IntelliJ IDEA, VS Code, GitHub);
- `img/diagrams/` — диаграммы в PNG (для вставки в пояснительную записку) и SVG;
- `img/screens/` — снимки экрана;
- `api/` — `openapi.json`, примеры запросов (`erp.http`, `samples/`), сценарий обмена `erp-demo.ps1`.

Пересборка картинок из исходников (нужен Node.js):

```powershell
npx -p @mermaid-js/mermaid-cli mmdc -i Project_Docs\diagrams\10_er.mmd -o Project_Docs\img\diagrams\10_er.png -b white -s 2
```
